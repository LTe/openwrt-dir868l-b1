tx_expand:
For private linear skb structures, replace skb_copy_expand + free with
pskb_expand_head. This still copies data but reuses the skb structure and
kernel code adjusts header/checksum offsets and unshares cloned linear data.
Shared skb structures and nonlinear packets retain the old copy path.
Failure frees the input and uses the existing drop/flush behavior.
Build02 applies to all lengths. Build03 adds tx_expand_min_len (default256)
so small ACK buffers retain the original path. Default tx_expand remains off.

The earlier local receive GRO benefit does NOT generalize to bridging.
Bridge RX worsens~27% in these paired CPU measurements. Therefore build03
adds opt-in rx_tcp_gro_local_data: bypass GRO for TCP DATA addressed to neither
the receiving netdev nor its master, while retaining existing ACK delivery.
Eligible locally addressed/routed data retains GRO. All-protocol rx_gro=1
still takes precedence. IPv6 extension headers retain the old bypass behavior.
The selector uses RCU for the upper-device lookup and does not alter packet
contents or invent RX checksum validity.

Build03 selective-GRO performance and final correctness are recorded in
runtime-01/gro-selective-paired and subsequent validation artifacts.
These experimental changes are not yet promoted into the package feed.
