## Changes in v0.3.0

- LuCI wireless configuration now offers WPA settings through the `broadcom` netifd driver
  type and reports the radio's real channel list and control channel.
- Improved netifd defaults and 40 MHz support on 2.4 GHz; added `wlblob-check` to verify the
  driver, iwinfo and netifd integration.
- Added opt-in receive GRO, RX/TX batching and A-MSDU header reuse. These experimental paths
  remain disabled by default.
- Removed redundant DMA mapping calls for coherent descriptors and corrected CTF ABI
  compatibility in the driver glue.
- Added real LuCI screenshots and measured Wi-Fi throughput to the README, with detailed
  driver research in separate documentation.

Hardware TCP checksum offload, selective TCP GRO and TX buffer expansion remain separate
development prototypes and are not included in this release. TSO is not enabled.
